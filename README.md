# ねこねこネオン迷路

夜のネオン迷路を小さな猫がかけぬける、シンプルな2Dタイムアタック迷路ゲームです。

ブラウザだけで遊べます（ビルド不要・外部ライブラリ不要）。

## 概要

- ランダム生成の迷路をゴールまで進む
- 制限時間（カウントダウン）あり。時間切れでゲームオーバー
- ⭐（星）を3つ集めるとゴールの扉が開く
- 🐟（魚）を取ると残り時間 +5 秒
- 全5ステージ。進むごとに迷路が大きくなる
- ベストクリアタイム（全ステージ合計）とハイスコアをブラウザに保存

## 遊び方

1. タイトル画面で「はじめる」を押す
2. 各ステージ開始前にステージ番号が表示される
3. 迷路内の星を3つ集めて扉（🔒 → 🚪）を開ける
4. 開いた扉に到達すると次のステージへ
5. 全5ステージクリアで全クリア！

## 操作方法

| 操作 | 内容 |
|------|------|
| 矢印キー / WASD | 上下左右に移動 |
| 画面下の十字ボタン | スマホ・タッチ操作用 |
| 🔊 ボタン | 効果音のミュート切替 |

## ファイル構成

```
index.html     … 画面とUI

ads.txt        … サイトルートの ads.txt
privacy.html   … プライバシーポリシー
operator.html  … 運営者情報
contact.html   … お問い合わせ
legal.css      … 案内ページのスタイル
README.md      … このファイル
```

## 遊び方（ローカル）

`index.html` をブラウザで開くか、任意の静的サーバーで配信してください。

例:

```bash
npx serve .
```

GitHub Pages ではリポジトリのサブパスでも動くよう、相対パスのみ使用しています。

## スコア・記録

- 星: +150 点
- 魚: +50 点（時間 +5 秒）
- ステージクリア: +300 点 + 残り時間ボーナス
- ベストクリアタイム / ハイスコアは `localStorage` に保存

## 広告（Google AdSense）

パブリッシャー ID は `ads-config.js` だけに書きます。値を空にすると、広告スクリプトは読み込まれません。

各ページの `head` から自動広告のスクリプトを読み込みます。ホスト名が `github.io` で終わる場合（GitHub Pages）は読み込みません。迷路・タイマー・操作の上に、手動の広告枠は置いていません。

プレイを遮らないよう、AdSense の管理画面ではアンカー広告と全画面（ビネット）広告をオフにしてください。配信面のオンオフはアカウント側の設定です。

`ads.txt` はサイトルート（`/ads.txt`）で配信します。

## 独自ドメイン（Vercel）

Google AdSense は `*.vercel.app` のサイトを追加できません。審査と配信には独自ドメインが必要です。

1. Vercel のプロジェクトで **Settings → Domains** を開く
2. 取得済みのドメインを追加する
3. 表示された DNS（A または CNAME）を、ドメインの管理画面に設定する
4. HTTPS が有効になったら、その独自ドメインを AdSense に追加する

ページ内のリンクは相対パスだけです。ドメインを付け替えても、HTML にホスト名を書き込む必要はありません。`ads.txt` は、そのドメインのサイトルートでそのまま配信されます。
